# 📸 React Image Gallery (Picsum API)

A simple React application that fetches and displays images from the [Picsum Photos API](https://picsum.photos/).  
It uses **Axios** for API requests, **React Hooks** for state management, and a custom `Card` component for rendering images.

---

## 🚀 Features
- Fetches images dynamically from the Picsum API.
- Pagination with **Prev** and **Next** buttons.
- Displays a loading state while fetching data.
- Responsive layout using **Tailwind CSS**.
- Clean separation of components (`App` and `Card`).

---

## 🛠️ Tech Stack
- **React** (Functional Components + Hooks)
- **Axios** (HTTP requests)
- **Tailwind CSS** (styling)
- **Picsum API** (image source)

---


## ⚙️ Installation & Setup

  1. Clone the repository:
   git clone https://github.com/your-username/react-image-gallery.git
   cd react-image-gallery

  2. npm install

  3. npm run dev

   
## 📖 Usage:
The app fetches 10 images per page.

Use the Prev and Next buttons to navigate between pages.

The current page number is displayed between the buttons.
